## itch.io hosting checklist

Grouped so you can work top to bottom. Based on itch.io's Content Creator Quality Guidelines and their HTML5 hosting rules.

### 1. Before you publish (page readiness)

- [ ] Have everything ready before you flip the page to Public. The moment you publish, it lands once on the "Most Recent" list and can never be bumped back to the top, so publish something you're proud of.
- [ ] While you finish the page, keep visibility set to **Draft** or **Restricted**. Those are safe to share with friends for testing and will not use up your "new release" slot.
- [ ] Do not create a second page later just to get a visibility "boost." Update this one page instead; a new page loses ratings, comments, and existing players.

### 2. Upload the game (HTML5 specifics)

- [ ] Zip the game so that **`index.html` is at the root of the zip** (not inside a subfolder). Since the whole game is a single file, the zip contains just `index.html`.
- [ ] Upload the zip, then tick **"This file will be played in the browser."**
- [ ] Set the embed **viewport size**. The game is responsive up to about 900px wide; try roughly **960 x 720** and adjust after previewing.
- [ ] Enable **"Mobile friendly"** (the game supports touch and 3-across cards on phones).
- [ ] Enable the **"Fullscreen button"** so players get the full board.
- [ ] Upload your files **directly to itch.io**. Do not just link out to another host or store.
- [ ] Preview the embedded game and play one full match to confirm it runs inside itch's iframe.

Notes specific to this build:
- Saves (decks, record, settings) live in the browser's storage on itch's game domain, so they persist per browser. The in-game **Profile export** is the backup and cross-device path; mention it in your description.
- The clipboard "Copy code" button may be blocked inside itch's sandboxed iframe; the game already falls back to showing the code in a text box, so this is fine.

### 3. Page assets (images)

- [ ] Add a **cover image**. This is the first thing people see when browsing. Recommended size **630 x 500** (minimum 315 x 250). An animated GIF is allowed and grabs attention.
- [ ] Make sure the cover has **no seizure-inducing flashing** (the game itself already supports reduced motion).
- [ ] Add **screenshots** (a duel with the range zones and hand, the deck builder, the Gauntlet ladder, and the fighter roster are all good picks). GIFs of a KO or a takedown work well here too.
- [ ] Do not use a misleading or unrepresentative image.

### 4. Metadata and classification (be accurate, do not over-tag)

- [ ] **Kind of project:** Game.
- [ ] **Platform / release type:** since the game runs in the browser, do **NOT** tick Windows, macOS, Linux, or Android. Those are only for downloadable executables. HTML5 is handled by the "played in the browser" upload, not a platform checkbox.
- [ ] **Pricing:** Free, or "No payments," or pay-what-you-want with a 0 minimum. (Do not set a fake price to fake a sale later.)
- [ ] **Genre:** Card Game (secondary: Strategy).
- [ ] **Tags:** use a few **relevant, suggested** tags, not synonyms and not your own name/title. Good candidates: `deckbuilding`, `card-battler`, `martial-arts`, `1v1`, `singleplayer`, `local-multiplayer`, `pvp`, `turn-based`, `mobile-friendly`, `pixel`-free (skip that one). Pick maybe 6 to 10 that actually fit.
- [ ] **Multiplayer:** set Local multiplayer / pass-and-play in the multiplayer section rather than as a tag.
- [ ] **Languages:** select **English** only. Do not select every language.
- [ ] **Accessibility:** fill these in honestly. This build supports **reduced motion**, **full keyboard**, **gamepad**, **screen-reader labels**, and **configurable difficulty**. Tag what applies.
- [ ] **Adult content:** none, leave it unmarked.

### 5. Generative-AI disclosure (read this one carefully)

- [ ] Use itch's **AI Disclosure** section on the edit page and answer it honestly. This is enforced, and getting it wrong risks delisting.
- [ ] What the game actually ships: the art is hand-authored inline SVG, and the sound is synthesized at runtime by code. Under itch's definition, self-contained algorithms with no external dataset (procedural audio, coded art, game AI) are **not** generative AI and do not by themselves require the tag.
- [ ] What to weigh: the **code and written copy were produced with AI assistance** (an LLM). itch's disclosure is about generative-AI content in the project. This is a genuine judgment call. If any player-facing text or asset was generated by an AI model, the safe and honest choice is to enable the disclosure. When unsure, disclosing is the low-risk option and only adds you to the "AI Assisted" browse page.

### 6. Description / page copy

- [ ] Write a clear description that matches what the game actually does (no overstated claims).
- [ ] State the controls (mouse/touch, number keys 1 to 9 to play cards, Enter to end turn, Esc to pause, gamepad supported).
- [ ] Include the honest selling points: **no data collected, no accounts, no third-party dependencies**, and that progress can be exported as a portable profile file.
- [ ] Add a short **credits** line and your contact (peterbrendanwrites@gmail.com), and note the license (all rights reserved, personal play).
- [ ] Link the design document if you want, but keep the main call to action "Play now."

### 7. After publishing (community, promotion, honesty)

- [ ] Announce it in itch's **Release announcements** board, not by spamming other games' comment sections.
- [ ] Do not add the game to unrelated game jams just for exposure.
- [ ] If you run a sale later (unlikely for a free game), do not keep it permanently "on sale" or fake the base price.
- [ ] Keep the single page and update it over time rather than re-uploading fresh pages for small changes.

## Suggested page description starter (paste and edit)

**Masters of the Way** is a one-on-one martial-arts card battler built from six real arts, each with its own way of fighting. Boxing owns the pocket, Taekwondo snipes from range, Judo turns standing into ground, BJJ finishes on the floor, Muay Thai bleeds you in the clinch, and Karate ends it in one strike.

Build a deck and pick your fight. Go pure and earn an art's mastery, or cross-train and cover every range. Win by knockout or force a tap.

- Free, plays in your browser on desktop and mobile
- About 5 to 10 minutes per duel
- Solo vs seven AI fighters, a Gauntlet run, and local pass-and-play
- A short tutorial to learn range and grappling
- Full keyboard, gamepad, and screen-reader support; reduced-motion option
- No accounts, no analytics, no data collected. Your decks and record stay on your device, and you can export a profile file to carry them anywhere.

Controls: mouse or touch. Number keys 1 to 9 play cards, Enter ends your turn, Esc pauses. Gamepad supported.
