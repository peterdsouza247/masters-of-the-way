# Masters of the Way — public roadmap

The current browser game is playable now. This roadmap names the direction of
development; it is not a release schedule or a promise that every idea will ship.
Player feedback will decide what deserves a full release.

## Now: browser playtest on itch.io

- Publish the existing single-file HTML5 game as a free browser game.
- Confirm the no-action stalemate fix and forfeit flow in real matches, not just
  in code. Test the tutorial, Gauntlet, local two-player profile handoff, and
  saving/importing a profile inside itch's embedded player.
- Collect useful feedback: where players get confused, whether they finish a
  duel, which arts they choose, and whether they would return for another run.

## Next: make the core worth returning to

- Improve balance and the legibility of range, grappling and submissions using
  actual playtest reports.
- Polish the screens and sound that players see repeatedly. Keep keyboard,
  controller, touch and reduced-motion play working as the interface changes.
- Review martial-arts terminology and portrayals with practitioners before a
  commercial release.

## Possible premium desktop game

A Steam edition would need a distinct paid experience beyond the free browser
duels. The leading candidate is a career or tournament mode with progression,
rivals and meaningful deck decisions between fights, packaged and tested as a
desktop application. A focused demo would let players try the combat before
buying. Scope and release plans will follow the browser playtest.

## Later possibilities

- An Android edition built and tested for sustained touch play on phones.
- Additional arts only where they create a new tactical choice.
- Online multiplayer only if the local combat and audience justify its ongoing
  complexity and operating cost.
